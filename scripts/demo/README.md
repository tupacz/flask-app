# 🎭 Scripts de Demostración

Scripts para mostrar las funcionalidades del sistema.

## 📝 Archivos

### `demo_navigation.py`
**Propósito**: Demostración interactiva de las funcionalidades de navegación
- Abre automáticamente las diferentes páginas del sistema
- Muestra todas las funcionalidades disponibles
- Guía paso a paso de la navegación
- Útil para presentaciones y demostraciones

**Funcionalidades que demuestra**:
- 🗳️ Pantalla Principal - Votar
- 🏆 Pantalla de Ganador
- 📊 Vista de Votos (protegida)
- 📚 Gestión de Libros
- 📱 Interfaz de Telegram

**Uso**:
```powershell
# Asegúrate de que el servidor esté corriendo
python scripts/demo/demo_navigation.py
```

### `summary_implementation.py`
**Propósito**: Resumen de todas las características implementadas
- Lista todas las funcionalidades completadas
- Muestra estadísticas del sistema
- Describe las capacidades técnicas
- Útil para documentación y reportes

**Información que muestra**:
- ✅ Características implementadas
- 📊 Capacidades del sistema de votación
- 🔐 Funcionalidades de seguridad
- 📱 Integración con Telegram
- 🏆 Sistema de ranking Condorcet

**Uso**:
```powershell
python scripts/demo/summary_implementation.py
```

## 🎯 Cuándo usar estos scripts

### `demo_navigation.py`
- Para mostrar el sistema a stakeholders
- Durante presentaciones
- Para verificar que toda la navegación funciona
- Como guía de las funcionalidades disponibles

### `summary_implementation.py`
- Para generar reportes de estado
- Para documentar capacidades
- Como resumen técnico del proyecto
- Para onboarding de nuevos desarrolladores
